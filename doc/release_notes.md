# Flutter Globe v1.0.2

Flutter Globe 1.0.2 is a documentation-only update. The package API and runtime behavior are unchanged.

## Changes

- Removed the mobile README preview.
- Added a second 1440 x 900 desktop preview from the real Data Layers example.
- Enabled the graticule and route layers in the capture so line work is clearly visible across the globe.

## Install

```bash
flutter pub add flutter_globe
```

See `CHANGELOG.md` and `doc/release_readiness.md` for the validation boundary.
