# Security policy

## Supported versions

Security fixes are provided for the latest stable `1.x` release.

## Reporting a vulnerability

Do not post vulnerabilities, credentials, or private location datasets in public issues. Use [GitHub private vulnerability reporting](https://github.com/ariaramin/flutter_globe/security/advisories/new) and include the affected version, platform, minimal reproduction, impact, and proposed mitigation.

Share only the minimum data required to reproduce the problem. Automated checks in this repository are quality controls, not a security audit or a response-time guarantee.
