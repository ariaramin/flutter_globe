# Flutter Globe example

Seven destinations: Showcase, Skins, Arcs, Markers, Data Layers, Playground, Benchmarks.

```bash
flutter pub get
flutter test
flutter run -d chrome
```

Use `flutter run --profile -d YOUR_DEVICE_ID` for native benchmark measurements. The [playground guide](../doc/playground.md) explains code export and fullscreen behavior; [benchmark methodology](../doc/benchmarks.md) defines the metrics and caveats.

This is sample geographic data, not a live network or flight feed. No API keys are required.
